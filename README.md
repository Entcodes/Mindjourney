# 心灵方块书屋 · MindCraft Library

一个**纯静态、零依赖**的虚拟学习空间：书架三层、共十五本"心情的书"，由一位戴帽子的心理学教授（第三人称叙述）陪你读完。
像素方块风格取自《我的世界》的视觉语言，配色是樱花木与少女粉。

> 这里是学习空间，不是心理治疗。若低落持续两周以上、影响到吃饭睡觉或上学，或出现伤害自己的念头，请立刻告诉信任的大人并寻求专业帮助（中国大陆：全国统一心理援助热线 **12356**，24 小时）。

## 一、七条需求与实现位置

| # | 需求 | 实现 |
|---|---|---|
| 1 | 数据库以书本形式呈现在书架上，两层各五本 | 第一、二层共 10 本；应后续追加需求新增第三层 5 本（见 §3） |
| 2 | 书本与书架为《我的世界》原型样式 | `js/pixel.js` 用 `box-shadow` 逐像素绘制书本／人物／信件，`css/style.css` 用 `repeating-linear-gradient` 画木板 |
| 3 | 有记忆清单，不限访问次数 | 「记忆清单」标签页，艾宾浩斯间隔 `1/2/4/7/15/30` 天，"记得"升级、"忘了"降级且当天再见 |
| 4 | 每日例行考试 10 题 | 「每日考试」从 64 题题库随机抽 10，逐题批改 + 解释，错题可回看；"再练一次"不计分 |
| 5 | 每日最多向教授提问 10 次 | 「问教授」按本地日期计数，午夜重置；回信来自离线回信库（关键词匹配，非联网 AI） |
| 6 | 第一本（红）暴怒缓解句 + 名著情感示范；第二本（绿）用权威方法给心情归类并给方法与场景 | 红书 `id: anger`；绿书 `id: moodmap`，内含 POMS / PANAS / Russell 情绪环状模型 / Gross 过程模型 / DBT-TIPP 的六类分组，每组配方法、适用场景与跳转书目 |
| 7 | 点人物帽子切换中英双语，同时口袋掉落一封写学习流程的信 | 顶栏人物帽子可点击：语言翻转 + 掉信动画 + 弹窗；14 封信收齐后随机重放，可在「信件柜」回看 |

## 二、直接打开就能用

1. 下载或克隆本仓库；
2. **双击 `index.html`**，浏览器即可打开，无需安装、无需服务器、无需联网。

所有脚本都是普通 `<script src>`（非 ES Module），因此在 `file://` 下也不会被 CORS 拦截。
进度保存在浏览器 `localStorage`（键名 `mindcraft-library-v1`），**不会上传到任何地方**；页脚"清空本地记录"可随时重置。

第三层的五本书按"一道题、两种文化各答一半"来编排：

| 书 | 核心难题 | 心理学抓手 | 中西对照 |

| 《第七天》余华 2013 | 死亡焦虑 / 被留下 | 恐惧管理理论、社会支持缓冲假说（Cohen & Wills）、延续性联结、低心情保护单 | 库伯勒-罗丝五阶段（并说明它不是关卡） |
| 《莫泊桑小说集》 | 比较 / 虚荣 / 期待 | 社会比较（Festinger）、物质目标与幸福（Kasser & Ryan）、道德绑架与自信训练、认知重评 | 吴敬梓《儒林外史·范进中举》 |

### 关于引文

书页里的句子分两类，并在界面上明确标注：

- `情节大意` / `中译大意` / `作者自述·大意转写`：不能逐字核对原文或依赖具体译本的，一律**用自己的话复述**，不冒充原文；
- 学术通说（如五阶段）标注为"学术通说（原书表述更谨慎）"。

**要在作文或论文里引用时，请回到原著核对，并记下版本与译者。** 本项目不提供原文摘录，只提供情节与大意。

## 四、目录结构

```
.
├── index.html              页面骨架（书架、五个标签页、弹窗）
├── css/style.css           像素风样式、三层书架、响应式与移动端缩放
└── js/
    ├── pixel.js            像素精灵：书本人物信件图标（box-shadow 绘制）
    ├── i18n.js             界面文案（中英各 99 条，键完全对齐）
    ├── data-books.js       第一、二层的 10 本书
    ├── data-books-shelf3.js第三层的 5 本书，并 concat 进 window.BOOKS
    ├── data-exam.js        64 题题库（跨全部 15 本书随机抽 10）
    ├── data-chat.js        14 封学习流程信 + 29 条教授回信 + 兜底回信
    └── app.js              状态、书架渲染、间隔重复、考试、提问、掉信
```

数据都是普通全局对象（`window.BOOKS` / `window.EXAM_BANK` / `window.LETTERS` / `window.PROFESSOR`），
**加一本书 = 往数组里加一个对象**，不需要改逻辑。字段结构见 `data-books.js` 顶部注释。

## 五、部署到 GitHub Pages（零命令行版，按钮级步骤）

> 站点全部用相对路径，所以放在仓库根目录时，Pages 地址 `https://你的用户名/仓库名/` 直接可用，不需要改任何配置。

### 方式 A：网页上传（推荐第一次用）

1. 打开 <https://github.com>，右上角 **Sign up** 注册（已登录则跳到第 3 步）；
2. 登录后点右上角 **`+` → New repository**；
3. **Repository name** 填 `mindcraft-library`（小写、连字符），**Description** 随意，可见性选 **Public**，勾选 **Add a README file** 反而会造成冲突，**不要勾**，点 **Create repository**；
4. 在新页面点 **`uploading files`** 链接（不是 "upload files"）；
5. **关键一步**：把文件**拖进浏览器窗口**时，请打开本地文件夹 `mindcraft-library`，全选**里面的内容**（`index.html`、`css` 文件夹、`js` 文件夹、`README.md`）拖进去。
   - ⚠️ 网页上传经常把整个外层文件夹"吞掉"或只上传了文件没上传子文件夹，导致 Pages 白屏。拖完后**在上传页面确认能看到 `css/` 和 `js/` 两个目录**再点 **Commit changes**；
   - ⚠️ 如果 `css`、`js` 变成了一行带斜杠的文件名（例如 `css/style.css`），说明被当成单个文件了——删掉它，改用方式 B；
6. 提交后回到仓库首页，点 **Settings**（顶部标签）→ 左侧 **Pages**；
7. **Build and deployment → Source** 选 **Deploy from a branch**；**Branch** 选 `main`，文件夹选 **`/ (root)`**，点 **Save**；
8. 等 1～2 分钟刷新这一页，会出现 **Your site is live at `https://你的用户名/mindcraft-library/`**，点它就是你的网站。

### 方式 B：用 Git 命令行（文件夹结构最稳）

```bash
git clone https://github.com/你的用户名/mindcraft-library.git
# 把 index.html / css / js / README.md 复制进刚克隆的目录
cd mindcraft-library
git add .
git status          # 确认 css/ 和 js/ 里的文件都在
git commit -m "add MindCraft Library static site"
git push
```

然后照方式 A 的第 6～8 步开启 Pages。

### 部署后自检

- 打开网址后按 **F12 → Console**，不应有红色报错；
- 若页面是"裸文字"没有粉色木板 → `css/style.css` 没上传成功；
- 若书架是空的 → `js/` 里的文件缺失，检查是否被当成文件名带斜杠的单文件。

### 更新内容

改了 `js/data-books-shelf3.js` 之后，在仓库页面点该文件 → **编辑（铅笔图标）** → **Commit changes**，1 分钟左右 Pages 自动重新发布。
